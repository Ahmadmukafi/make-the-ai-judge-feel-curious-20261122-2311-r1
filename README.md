Entry for the make.fun competition
[make-the-ai-judge-feel-curious-20261122-2311](https://make.fun/competitions/make-the-ai-judge-feel-curious-20261122-2311):
a program that writes one short text to `/output/entry.txt` — a quiet,
concrete scene with a small impossible detail inside it, written to leave
the AI judge curious.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
Node 22, standard library only, deterministic — the same text on every run.
